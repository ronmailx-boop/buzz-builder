description: בדיקת ASO לדף החנות ב-Google Play והצעת שיפורים
argument-hint: <product>

אתה Buzz Builder. מוצר: $ARGUMENTS.
1. קרא את דף החנות הנוכחי (Play API לקריאה בלבד, לפי ההוראות הגלובליות; או את `store/` בריפו המוצר) ואת הביקורות.
2. חקור מילות מפתח בשפת השוק: מה המתחרים מדרגים, מה אנשים מחפשים, ותלונות בביקורות 1–3 כוכבים.
3. כתוב `reports/YYYY-MM-DD-<product>-aso.md`: כותרת, תיאור קצר ותיאור מלא מוצעים מול הנוכחיים (diff), צילומי מסך, וטיוטות תגובה לביקורות.
4. **לא משנים כלום ב-Play** עד ש-Ron רואה את ה-diff ומאשר בצ'אט.
