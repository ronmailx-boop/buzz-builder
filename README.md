# Buzz Builder 🐝

סוכן השיווק, המכירות וההפצה של **Vplus Studio**. רץ בסשנים של Claude Code בענן על הריפו הזה.

- כותב ומתזמן פוסטים ל-**YouTube, ‏Facebook, ‏Instagram ו-X**. כל שבוע נפתח PR, ו-**Merge = אישור**.
  GitHub Actions מפרסם כל שעה את מה שהגיע זמנו.
- מכין **כתבות תדמית, הודעות לעיתונות** וטיוטות פנייה לעיתונאים (`/press-kit`).
- משפר **ASO ב-Google Play** ו-SEO באתרים (`/aso-review`), ובונה תוכניות השקה (`/launch-plan`).

התקנה חד-פעמית: [`docs/SETUP.md`](docs/SETUP.md).

| תיקייה | מה יש בה |
|---|---|
| `queue/approved/` | פוסטים מאושרים שמחכים לזמן שלהם |
| `queue/published/` | פוסטים שפורסמו, עם קישור |
| `queue/failed/` | פוסטים שנכשלו, עם השגיאה |
| `drafts/` | טיוטות לקהילות ופורומים, Ron מפרסם בעצמו |
| `press/` | הודעות לעיתונות, כתבות, רשימות מדיה |
| `media/` | תמונות לפוסטים (בלי וידאו) |
| `reports/` | תוכניות ודוחות |
